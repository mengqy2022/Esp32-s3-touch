VOCAB LAB / BOOKS V4 测试步骤

一、编译
1. idf.py fullclean
2. idf.py build
3. idf.py flash monitor

二、本地词书
1. SD 卡放入 /vocabulary/books/*.csv
2. 支持 UTF-8 CSV，也支持带 UTF-8 BOM 的 CSV
3. 进入 VOCAB LAB -> BOOKS
4. 本地词书显示在 LOCAL BOOKS - TAP TO LEARN
5. 点击词书后应直接进入 LEARN
6. 当前词书返回 BOOKS 后应显示 [ACTIVE]

三、在线下载
1. Wi-Fi 连通，SD 已挂载
2. 点击紫色 [DOWNLOAD]
3. 顶部框应立即显示书名 + DOWNLOADING/百分比/KB
4. 网络源优先使用 jsDelivr CDN；失败自动尝试 GitHub Raw
5. 下载后显示 INSTALLING TO SD...
6. 成功显示绿色 DONE: xxx / Saved: xxx.csv
7. 对应条目变为 [ON SD]，并自动设为 ACTIVE
8. 再点击 [ON SD] 应直接进入 LEARN，不会重复下载

四、失败提示
- 无 Wi-Fi：DOWNLOAD BLOCKED / Connect Wi-Fi first
- 无 SD：DOWNLOAD BLOCKED / Mount SD card first
- 两个下载源都失败：DOWNLOAD FAILED
- 本地 CSV 列格式错误：BOOK ERROR / Need word + meaning columns

五、BOOKS 页面布局
- 顶部下载状态框固定 38px 高
- 列表从 y=81 开始
- 不再显示原来过长的 “local CSV books appear above”
- ONLINE BOOKS 标题只存在于滚动列表内部，不应与状态框重叠
