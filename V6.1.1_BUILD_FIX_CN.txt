MQY ESP32 Touch Vocab Toolbox - V6.1.1 构建修复

根据你提供的 ESP-IDF 5.5.4 / GCC 14.2.0 构建日志，本次修正：

1. 修复 DRAM .bss 溢出
   日志：dram0_0_seg overflowed by 14632 bytes

   根因：
   DICTATION 手写区域使用了 216 x 82 的 16-bit 真彩色静态 Canvas。
   仅该数组就占用 35,424 字节内部 DRAM。

   修改：
   改为 LVGL 8.4 的 LV_IMG_CF_INDEXED_1BIT 两色 Canvas：
   Palette 0 = 背景色
   Palette 1 = 手写笔迹色

   预计静态缓冲约 2.2 KB，相比原方案释放约 33 KB DRAM。
   手写功能保留，不改成动态大块 malloc，避免运行时内存碎片。

2. 去除 vocabulary.c 两个 warning
   - 删除未使用的 hex4()
   - 删除未使用的 utf8_put()

3. 没有通过关闭 warning 或修改 -Werror 来掩盖问题。

建议重新构建：
idf.py fullclean
idf.py build

构建成功后：
idf.py flash monitor

版本：
MQY ESP32 Touch Vocab Toolbox V6.1.1
