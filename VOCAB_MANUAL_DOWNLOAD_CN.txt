WORDBOOKS 手工下载 / SD 卡使用说明

推荐总入口：
https://github.com/grhliu/wordtyper-vocabularies

数据说明：该仓库词库由 ECDICT 派生，仓库声明为 MIT License。

【最简单的用法】
1. 在电脑上下载下面任意一个 .json。
2. SD 卡使用 FAT32，文件放到：/vocabulary/books/
   例如：/vocabulary/books/cet4.json
3. 插回 ESP32，进入 VOCAB LAB -> WORDBOOKS。
4. 在 SD BOOKS 中点击该词库。
5. 固件会在 SD 卡本地自动转换为同名 .csv，然后设为 ACTIVE 并进入 LEARN。
6. 以后优先使用 .csv；原始 .json 可以保留作为备份。

【也支持 CSV】
直接放 /vocabulary/books/*.csv 即可。CSV 表头至少要能识别：word + meaning。
推荐标准表头：word,phonetic,meaning,example

【在线下载仍保留】
WORDBOOKS -> ONLINE BOOKS 的 [DOWNLOAD] 功能没有删除：
优先 jsDelivr，失败再尝试 GitHub Raw。
如果 ESP32 网络访问 GitHub/CDN 不稳定，建议使用上面的电脑下载 + SD 卡导入方式。

【V6 首次加载提示】
首次点击 .json 时，设备会在后台转换并显示 SD JSON IMPORT 百分比与已转换词数；转换完成后会自动生成同名 .csv。以后选择该词库直接使用 CSV，不需要重复转换。

【每日计划与时间】
词库本身可完全离线使用。为了让“今天/明天”的每日计划准确，设备首次使用以及关机跨天后建议先连接 Wi-Fi，等待 VOCAB LAB 显示 DATE OK；设备会缓存最后一次可信日期，没网时不会误跳到 1970。
