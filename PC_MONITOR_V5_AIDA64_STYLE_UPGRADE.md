# PC MONITOR v5.0 AIDA64 Style Edition

## Dashboard

Added professional hardware monitoring layout:

- CPU circular gauge
- GPU circular gauge
- MEM gauge
- Temperature panels
- Network throughput panel
- Sensor history graph area

## New monitoring channels

CPU:
- Usage %
- Temperature
- Frequency

GPU:
- Usage %
- Temperature
- VRAM usage

Memory:
- Usage %
- Used MB
- Total MB

Network:
- RX KB/s
- TX KB/s

Extended:
- Fan RPM
- SSD temperature
- Motherboard temperature
- Voltage

## History

60 seconds rolling history:

CPU usage
GPU usage
Temperature
Network speed

## Protocol extension

STAT|CPU|GPU|CPU_TEMP|GPU_TEMP|MEM|MEM_USED|MEM_TOTAL|RX_KBPS|TX_KBPS|CPU_FREQ|GPU_VRAM|FAN_RPM|SSD_TEMP

AIDA64 SensorPanel style:
