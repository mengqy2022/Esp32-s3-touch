# Build fix - 2026-09-01

Fixed the ESP-IDF 5.5.4 build failure in `main/ui.c`.

Compiler error:
`-Werror=format-truncation` in `refresh_inventory_window()`.

Cause:
The history display buffer was `char line[96]`, while the compiler could prove
that the formatted output may reach about 109 bytes.

Fix:
Changed the local history line buffer from 96 bytes to 160 bytes.
No inventory file format or UI behavior was changed by this build fix.

The unrelated `unused-function` / `unused-variable` messages are warnings only;
this project already compiles them with `-Wno-error=...`, so they were not the
cause of the failed build.
